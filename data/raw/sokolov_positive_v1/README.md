# Позитивный датасет Соколова v1

1000 JPEG, по 250 кадров из лекций 01, 03, 04 и 11. Все примеры имеют метку `1` (`sokolov`), согласно разметке владельца проекта. Негативных примеров пока нет.

Изображения в `positive/` — кропы окна веб-камеры размером 240×116 px без нижней подписи имени, без увеличения и аугментаций. Это исходники для последующего выделения и выравнивания лиц, а не готовый `face_crop` для обучения.

Кадры выбраны равномерно, с интервалом примерно 16–19 секунд и отступом 10 секунд от начала и конца записи. `manifest.csv` содержит относительный путь от этой папки, метку, исходное видео, время кадра и координаты кропа. `source_crop_sha256` — хеш RGB-пикселей до JPEG-сжатия, а не хеш файла JPEG.

`crop_coordinates.json` описывает исходные окна камеры и сохранённые кропы. Координаты с нуля от левого верхнего угла, правая и нижняя границы не включены. `validation.json` — отчёт проверки; `preview.jpg` — обзор.

Train/validation/test ещё не назначены. При интеграции в основной манифест используйте имя исходной лекции как общий `source_id` для всех её кадров и разделяйте данные по источникам. Файл `manifest.csv` сохраняет исходную схему извлечения; это ещё не `data/manifests/raw.csv`, требующий назначения внешнего `partition`.

Исходные видео и ZIP-архив не включены. Датасет явно включён в Git по запросу владельца проекта; остальные локальные данные остаются исключены.
