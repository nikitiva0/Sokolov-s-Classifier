# Локальное обучение на Mac (Apple Silicon)

Ноутбук `notebooks/local_train_mps.ipynb` выполняет полный запуск двух моделей, оценку,
генерацию из пяти шумов и отчёт.

Обучение, оценка классификаторов и оптимизация изображений используют строго `mps`.
`PYTORCH_ENABLE_MPS_FALLBACK=0`: при недоступном MPS выполнение останавливается.
SCRFD, декодирование изображений и графики работают на CPU.
В локальных TOML сохранены исходные 15 эпох ResNet18, 5 эпох ArcFace и batch size 32;
`num_workers=0` позволяет запускать из ноутбука без дочерних загрузчиков данных macOS.

## Запуск

Из корня репозитория, используя окружение с зависимостями проекта и
`nbclient==0.10.2`, `nbformat==5.10.4`, `ipykernel==6.29.5`:

```sh
.venv/bin/python tools/run_local_notebook.py
```

Локальный Jupyter kernel создаётся внутри `work/jupyter/kernels/`, настройки пользователя
не изменяются. Вывод и ошибки сохраняются в выполненном ноутбуке:
`work/local-mps/local_train_mps_v3.executed.ipynb`.

До запуска нужны опубликованный позитивный датасет, FairFace, дополнение из [описания v3](DOMAIN_REPAIR.md) и исходные веса. Текущие изменения подготовлены без нового обучения.
Локальные конфиги используют FairFace из
`work/kaggle-cache/datasets/mehmoodsheikh/fairface-dataset/versions/1`.
При другом расположении измените `fairface_dir` одинаково в обоих
`configs/*_local_mps.toml`. Параметры разбиения и подготовки должны совпадать.
FairFace можно заранее скачать через `kagglehub.dataset_download` с переменной
`KAGGLEHUB_CACHE`, указывающей на абсолютный путь `work/kaggle-cache`.

ResNet18 использует штатные веса torchvision `IMAGENET1K_V1` из
`work/torch-cache/hub/checkpoints/`. ArcFace ожидает совместимый iResNet50/MS1MV3
в `checkpoints/arcface/iresnet50_ms1mv3.pt`; SHA-256 зафиксирован в локальном TOML.
Во время подготовки текущего запуска использовано зеркало
`https://github.com/vietbacnguyen96/AI_Awards_Server/releases/download/v1.0.0/backbone.pth`;
это зеркало опубликованных весов, а не официальный URL InsightFace. Происхождение
и хеш сохранены локально в `checkpoints/arcface/source.json`. Подмена случайными
весами не допускается. Детектор: `checkpoints/insightface/models/buffalo_l/det_10g.onnx`.
После кеширования всех исходных файлов запуск не требует скачивания.

## Объединённая версия: данные и кеши

Локальные TOML сохраняют состав данных v3: собранные наборы `web_positive_v2`, `web_negative_v2`
и `user_v3` ([HARVEST.md](HARVEST.md)) в них не подключены. Чтобы обучить локально на объединённом
наборе, задайте одинаково в обоих `configs/*_local_mps.toml` ключи `data.web_positive_dir`,
`data.web_negative_dir`, `data.user_dir` и новые пути `raw_manifest`/`prepared_manifest`.

Формат raw.csv (схема 3) и подготовленного манифеста (схема 3) изменился: основной кадр при
нескольких лицах, pHash выровненных лиц, статус `near_duplicate`. Ранее построенный
`data/manifests/domain_v3/raw.csv` отклоняется с сообщением о других входных данных — удалите его
(пересборка без детекции). Подготовленные кропы прежних версий можно использовать через
`data.reuse_prepared_manifest`: повторно применяются сохранённые детекции, кропы пересчитываются только
для кадров с несколькими лицами. Для ResNet18 в локальных конфигах дообучается только `layer4`
(`training.finetune_blocks = 1` по умолчанию), как в v3.

## Панель прогресса

В отдельном терминале:

```sh
.venv/bin/python tools/monitor_training.py --run-dir outputs/runs/domain-mps-v3
```

Открыть http://127.0.0.1:8765. Панель читает реальные файлы запуска каждые две секунды:
этап ноутбука, число обработанных изображений, батчи и эпохи, loss, validation AP,
число завершённых генераций и итоговый отчёт. Сервер доступен только на этом компьютере.
Время окончания заранее не прогнозируется.

## Результаты и продолжение

Все результаты находятся в `outputs/runs/domain-mps-v3/`:

- `resnet18/`, `arcface/`: лучшие веса и `last.pt`, история, метрики, предсказания.
- `best_model.pt`, `best_model.json`: победитель по среднему validation AP доменов.
- `synthesis/`: пять шумов, промежуточные изображения и кривые оценок.
- `report/report.html`, `report.zip`: отчёт для просмотра и скачивания.

Повтор той же команды проверяет кеш данных, пропускает завершённое обучение и продолжает
незавершённое с последней сохранённой эпохи `last.pt`. Если остановка произошла до
первого checkpoint, сохраните/переименуйте незавершённую папку модели перед новым запуском.
Не меняйте конфиг и данные при продолжении — их хеши проверяются.
Для нового эксперимента задайте другое имя через `--run-dir outputs/runs/new-experiment`
и другое имя исполненного ноутбука через `--output`. Если меняется подготовка данных,
также задайте новую папку `prepared_manifest` в обоих локальных TOML.

Новый split изолирует лекции и связанные похожими фото группы, целевые доли 70/15/15 приблизительные.
Пять пользовательских фото принудительно остаются в train. Личности FairFace могут пересекаться. Ноутбук не
публикует файлы на GitHub. Команда `publish-report` остаётся отдельным действием.

## Исправление масштаба детектора (v2)

SCRFD получает изображение 640×640 с чёрным полем справа и снизу. Исходник
уменьшается, если он больше этого размера, а небольшие изображения сохраняют
исходный масштаб. Это устраняет увеличение тесных кропов FairFace с 224 до 640,
при котором детектор терял почти все негативные лица. Один алгоритм применяется
к обоим классам. Координаты и ключевые точки переводятся обратно в исходник.
Политика записана как `shrink_only_top_left_pad_v1` в аудит и используется локальным UI.

`data.min_detector_coverage=0.8` проверяет долю пригодных однозначных лиц отдельно
для обоих классов в каждой части выборки. Если покрытие ниже, подготовка не
помечается завершённой, а обучение не начинается. Проверка также выполняется
при чтении кеша и перед обучением. После исправления старый кеш несовместим:
локальный v2 использует `data/processed/local_mps_v2/`, исходная выборка и split
сохранены. Плохой v1 остаётся отдельно для сравнения.

Панель автоматически следует каталогу текущего запуска. Защита от обычного сна
включается на время работы процесса ноутбука; она не отменяет сон при закрытии крышки.
После обучения запустите `.venv/bin/python tools/serve_ui.py --run-dir outputs/runs/domain-mps-v3 --device mps`
и откройте http://127.0.0.1:8766 для проверки фотографий. [Инструкция](LOCAL_UI.md).
