# Проверка фотографий на компьютере

Из корня проекта:

```sh
.venv/bin/python tools/serve_ui.py
```

Откройте **http://127.0.0.1:8766**. Нажмите на область загрузки или перетащите
фотографию, затем нажмите **«Проверить фото»**. Поддерживаются JPG, PNG и WebP
размером до 15 МБ и до 40 мегапикселей. EXIF-поворот учитывается.

На фото появятся рамки и номера лиц, ниже — результат каждого лица и оценка модели.
Если хотя бы одно лицо прошло сохранённый порог, результат — «На фото найден Соколов».
Отсутствие лица и ошибка выравнивания показываются отдельно. Оценка модели не является
калиброванной вероятностью. Для окончания работы нажмите Ctrl+C в терминале.

Фотографии обрабатываются в памяти и не записываются на диск. Сервер слушает только
127.0.0.1: другие компьютеры к нему не подключаются. Интернет для проверки не нужен,
если обученные веса и детектор уже сохранены локально.

## Выбор запуска и ускорителя

По умолчанию используется `outputs/runs/local-mps-v2/`. Другой завершённый запуск:

```sh
.venv/bin/python tools/serve_ui.py --run-dir outputs/runs/my-run --port 8766
```

На Mac с Apple Silicon автоматически выбирается MPS; на ПК без ускорителя — CPU.
Выбор можно задать явно:

```sh
.venv/bin/python tools/serve_ui.py --device mps
.venv/bin/python tools/serve_ui.py --device cpu
```

Эквивалент после установки проекта: `python -m sokolov serve --run-dir ...`.

Используется победитель из `best_model.pt`, выбранный по validation AP, и порог
из `<архитектура>/threshold.json`. Контрольные суммы проверяются при запуске.
Случайные технические веса и старый детектор с увеличением тесных кропов отклоняются.
Нормализация, SCRFD и выравнивание совпадают с обучением. Повторного обучения нет.

## Другой компьютер

Нужен Python 3.11/3.12 и зависимости из `requirements-kaggle.txt`:

```sh
python -m venv .venv
# Активируйте окружение: Windows — .venv\Scripts\activate, macOS/Linux — source .venv/bin/activate
python -m pip install -r requirements-kaggle.txt
python tools/serve_ui.py --device cpu
```

Скопируйте из обученного запуска:

- `best_model.pt`, `best_model.json`;
- `resnet18/threshold.json` или `arcface/threshold.json` для выбранного победителя;
- `data/data_audit.json`;
- детектор `checkpoints/insightface/models/buffalo_l/det_10g.onnx`.

Путь к папке с детектором можно изменить через `--detector-root /path/to/insightface`.
Исходные фотографии, FairFace, подготовленные кропы и исходные предобученные веса
для запуска UI не нужны. Нужны именно обученные файлы; они не включены в GitHub.

Текущий test получен случайным разбиением кадров лекций. Качество на новой лекции
и произвольных фотографиях следует проверять отдельно.
