# Техническая проверка реализации

Проверено локально 31 октября 2026 года, CPU, macOS ARM64, Python 3.12.15.

## Выполнено

- 14 unit/integration-тестов: все прошли. Последний полный прогон — 22.6 секунды.
- Проверены оба TOML-конфига через CLI без ML-импортов и загрузок.
- Проверены синтаксис Python, формат/синтаксис 12 ячеек Kaggle Notebook и отсутствие ошибок whitespace в Git diff.
- pip check установленной локальной ML-среды: конфликтов нет. Разрешение полного requirements-kaggle.txt дополнительно проверено через pip --dry-run; это не проверка исполнения всего окружения на Kaggle GPU.

## Что проверяет интеграционный прогон

40 искусственных RGB-изображений, по 20 на класс; небольшой fixture-детектор с заданными ключевыми точками. Отдельный тест моделирует no_face, multiple_faces, повреждённый файл, повторный файл и конфликтующие метки.

Используются настоящие PyTorch ResNet18 и официальный iResNet50 с технической случайной инициализацией. ResNet18 обучается две эпохи: остановка после первой и продолжение совпали с непрерывным запуском по истории и всем тензорам состояния. ArcFace обучает бинарную голову одну эпоху.

Проверены формы входов/выходов, изменение головы, неизменность encoder и его BatchNorm при заморозке, строгая загрузка checkpoint, отклонение несовместимых/отсутствующих весов. Проверены общее разбиение, точные размеры 4200/900/900 для 6000 примеров, сохранение внешнего test и изоляция его групп.

Обучение вызывает только validation-предсказания; ранний checkpoint сохраняется при равном AP. Изменённые параметры продолжения и конфигурация подготовки отклоняются. Метрики проверяются на известных предсказаниях, включая положительный пропуск детектора и threshold=0.

Сформированы реальные файлы технического Markdown/HTML-отчёта с PNG, JSON/CSV, окружением и историей. График обучения просмотрен визуально. Технический отчёт хранится локально в `outputs/runs/technical-smoke/report/` (исключён из Git); это не результат качества на фотографиях Соколова.

Тест публикации проверяет запрет технического отчёта, allowlist, хеши файлов, тестовый транспорт и сохранность отчёта при сетевой ошибке. Сетевой GitHub push в тестах не выполняется.

## Что не утверждается

На этапе первоначальных технических тестов загрузка FairFace и полное обучение не выполнялись. Полный локальный MPS-запуск с реальными данными и предобученными весами описан в дополнении ниже. Kaggle GPU-запуск и публикация реального отчёта не выполнялись. Метрики технических изображений нельзя интерпретировать как качество распознавания.

Версии локально проверенных основных библиотек: torch 2.5.1, torchvision 0.20.1, numpy 1.26.4, scipy 1.15.2, scikit-learn 1.6.1, Pillow 11.1.0, ImageHash 4.3.2, matplotlib 3.10.0, Markdown 3.7, opencv-python-headless 4.10.0.84, scikit-image 0.25.2.

Исходник iResNet50 взят из официального deepinsight/insightface, ревизия и SHA-256 сохранены в backbones/NOTICE.md вместе с лицензией. Предупреждение о deprecated torch.cuda.amp.autocast находится в неизменённом upstream-файле; при fp16=False оно не меняет вычисления.

## Дополнение: генерация из лучшей модели

Добавлены проверки выбора победителя по validation AP, стабильного разрешения равенства и независимости выбора от test-метрик. `best_model.pt` сохраняется как точная копия выбранного best.pt; SHA-256 фиксируется рядом.

Проверены обе реальные архитектуры (технические случайные веса), три шага оптимизации пикселей, конечный ненулевой входной градиент, неизменность весов, диапазон [0,1], воспроизводимость одного seed, совпадение оценок сохранённых PNG с повторным forward. Смена настроек и изменение артефактов обнаруживаются, повторный запуск использует кеш.

Интеграционный тест выбирает победителя после обучения, удаляет raw-манифест и генерирует пять вариантов из сохранённой модели; создаёт обновлённый отчёт с промежуточными шагами, графиками и сравнением seed. Исходные датасеты и pretrained файлы для генерации не требуются. Ноутбук обновлён и проверен: 14 корректных ячеек. Всего 17 тестов; полный прогон исходных 16 и отдельная проверка расширенного allowlist публикации прошли; это технический прогон, не результат на фотографиях Соколова.

## Исправление

Небольшие исходники больше не увеличиваются до 640×640. Они сохраняют исходный
масштаб с чёрным полем справа и снизу; большие изображения уменьшаются.
Координаты и ключевые точки переводятся обратно в исходное изображение.
Один алгоритм применяется к обоим классам и записан в мобильный manifest.

| Показатель | До исправления | После |
|---|---:|---:|
| Пригодные негативные лица / 5000 | 46 | 4944 |
| Пригодные позитивные лица / 1000 | 994 | 998 |
| Негативные лица в test / 750 | 7 | 744 |

Train: 698 позитивов + 3459 негативов; val: 150 + 741; test: 150 + 744.
Исходные 6000 изображений и назначения split совпадают с v1 побайтно.
Проверка `min_detector_coverage=0.8` останавливает подготовку/обучение при низком
покрытии любого класса в любой части выборки, включая чтение кеша.
Старый кеш подготовки отклоняется по версии и политике масштабирования.
